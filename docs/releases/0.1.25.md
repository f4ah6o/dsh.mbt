# dsh.mbt 0.1.25

This version delivers **macOS 13+ / Apple Silicon artifacts only**: `dsh-darwin-aarch64` and `Dsh-macos-arm64.zip`. No Linux or Windows artifacts are delivered in this release. Linux X11 and Windows are not qualified by this release; their absence is not a successful platform validation. The Mooncakes package is published as source, with macOS Apple Silicon as this version's qualified native platform.

## Changes

- The raw macOS CLI now embeds the complete signed Dsh.app and its private worker helper. The same CLI can launch `dsh desktop`; the separate app ZIP remains available.
- Selecting a ChatGPT model explicitly saves and activates that provider across root requests, ACP and subagents. Provider changes reject stale retries, streams and results. Settings can restore the startup provider; signing out of ChatGPT requires authentication instead of silently using an API key.
- macOS extraction checks payload bounds, checksum, archive paths/types, the exact file manifest and signatures. Concurrent starts share a private version/content cache; quarantine is preserved, and existing entries are not silently replaced.

## Compatibility

The protected ChatGPT store now writes format 2 with its provider choice. Format 1 keeps the startup route until a model is explicitly selected. Older dsh versions cannot read format 2; retain a backup before downgrading.

The macOS app is ad-hoc signed, without Developer ID signing or notarization. No real-account inference or physical-input qualification is claimed. Native frame, resize and shutdown checks and synthetic provider HTTP regressions were exercised during preparation.
